# 大规模、高竞争故障快照留出验证

目标仍为在故障瞬间给定的在制状态上，完成全部有效晶圆并求出最迟允许维修延迟。此批固定为可到达的单臂末道工序快照，具有独立源腔、空故障腔和统一搬运时间。研究结论适用于本批合成数据。

## 数据和协议

在首次求解前固定 36 个输入、种子、四个执行入口、预算、运行次序和代码摘要。16、20、24 片各 12 例，每个规模交叉两档候选腔竞争、三档期限/路由、两个种子。原调参语料最多 12 片。新快照沿用原模拟器的物理历史，重新生成末道合法路线、驻留和持片期限，并复核历史可达。高竞争只配置两个健康末道腔，一部分路线只用其中一个；中竞争配置四至五个健康末道腔。每个实例的实际不同候选腔数、晶圆数与腔数之比、最多几片共享同一候选腔均见清单。三类设计分别为紧源期限、接近搬运容量的期限、较宽期限且每片有健康路线。生成器没有利用求解结果筛选。每种设计与结果的关系应以运行记录为准。

## 首轮结果

| 按时证明的快照数（共 36 例） | 1 秒 | 30 秒 |
|---|---:|---:|
| 单独调用末道精确工具 | 5 | 16 |
| 固定次序直接调用全部工具 | 24 | 26 |
| 同一决策策略由普通函数执行 | 24 | 26 |
| 离线 LangGraph Agent | 24 | 26 |

Agent 相对两个多工具对照均为零个新增、零个丢失。对双方都证明的相同实例计算逐例用时差，Agent 相对同策略函数的中位差分别为 +7.6、+8.5 毫秒。1 秒下对单次精确工具新增 19 例；30 秒新增 11 例、丢 1 例，净增 10 例。已有数据支持共享的快速判据和健康腔见证构造在本样本上有用。两种无需 LangGraph 的工具组合都取得了相同的边界证明数，无法从这些结果认定 Agent 或图执行有额外证明收益。绝对墙钟数值限于本机。

Agent 在两档均证明全部 12 个紧期限例立即修复仍不可恢复，全部 12 个宽期限可绕行例边界无穷。临界期限组的 12 例在 1 秒下均 UNKNOWN；30 秒多证明了 16-m-f1 和 16-m-f2 的有限边界，分别为 90.125 和 89.625 秒。其余 10 例中，5 例已有合法下界但上界未闭合，5 例连完成方案都未取得。10 例的主要计时项均为 CP-SAT 搜索，日志见逐例表。在 20-m-f2 上，单独精确工具首轮达到 107.25 秒并证明最优维修边界，Agent 首轮下界为 90.25 秒；反序四组均为 UNKNOWN。该例的数学边界已由单工具证明，Agent 的预算内状态仍按 UNKNOWN 报告。

按冻结代码，旧的序号上界只对至多 14 片的部分末道状态适用。本批 16–24 片临界期限例进入末道精确求解后，Agent 接收一次工具结果即结束。此处实测收益主要体现于冲突判据或构造能提前给出证书的输入。全表保留了有证明的状态、未证的区间、超时、反序波动以及用时退步。

## 区间退步和独立重放

同属 UNKNOWN 时也有差别。相对固定工具组合，1 秒首轮 Agent 在 16-m-f2 的区间更强，在 20-m-f1、24-m-f1 返回的区间更弱。30 秒首轮在 16-h-f1、24-m-f2 更强，在 20-m-f2 更弱。这些实例的较强下界均需合法见证。1 秒首轮，20-m-f1、24-m-f1、24-m-f2 的精确工具找到了可行方案，整次返回超过墙钟上限，按协议不计入准时的下界。

两档合计 480 次计时调用，其中 233 条记录附有方案。按快照、维修时刻、完工时间、方案内容去重，69 份不同的见证均通过原版 Simulator 后缀及整机重放。对按时未证的方案也按相同规则复核，审计不会改变准时证明数。

## 对照口径

| 标识 | 执行方式 | 对照作用 |
|---|---|---|
| single | 普通函数只调用适用子类的精确求解工具 solve_terminal，共用路线证书和快照准备。工具内部保留原 CP-SAT 切换、剪枝和验证 | 衡量加入多工具组合的整体变化 |
| fixed | 普通函数按固定次序调用数学冲突判据、健康腔方案构造、搬运序号求解、末道 CP-SAT。有完整证明就返回，工具适用条件照常检查 | 在相同工具集和早停能力下比较策略选择 |
| plain | 普通函数执行既有 adaptive 策略，使用 fast=True、graph=False | 与 Agent 完全相同的策略和工具，隔离 LangGraph 执行层 |
| agent | 既有离线 LangGraph 与确定性策略，使用 fast=True、graph=True | 本轮待测系统 |

每对方法读相同输入，在同一 CPU 核运行，求解器单线程。1 秒档全量反序；30 秒档首轮四组边界分类有差异时对四组全部反序。汇总只计首轮，每个实例权重相同。共用原来的 85% 内部预算和外部截止判分规则，超额返回记 UNKNOWN。预算包括故障历史校验、建模、工具选择、求解和在线重放。程序启动、预先导入、读盘、计时外归档审计单独计算。阶段计时为互斥计时，other 包括框架、证书计算和未单列开销。计时采样误差和机器负载会影响小幅速度差异。
