# 故障恢复结项数据

[18 例最终状态](18-outcomes.csv)汇总累计证据。[6 例的前后区间](six-intervals.csv)列出最后一次上界专项结果。区间左端有可重放方案，严格超过右端的时刻已被排除。9 例有限边界、3 例立即不可恢复、6 例区间未闭合。所有结果均在相应快照的设备与工艺假设下成立。

[冻结盲测原始配对](../final-holdout/paired-effects.json)在相同 18 个输入上比较离线 Agent 与同策略普通函数。首轮在 1 秒均为 5/18，在 30 秒均为 11/18。随后针对同一批快照的诊断和专项求证产生第 12 个结论，属于累计研究结果。

## 两个主讲案例

- [16 片有限边界和完整动作表](../final-holdout/b30/blind-16-m-f1/0-agent.json)。W0 最迟取完为 571 刻度，最多持片 130 刻度，放片耗时 7 刻度，故障腔最晚必须在 694 刻度修好。每秒 8 刻度，上界为 86.75 秒。全批方案在该上界通过重放。
- [20 片立即不可恢复证据](../final-holdout/b30/blind-20-h-f1/0-agent.json)。10 片必须共用 H1。逐一假定哪片最后从源腔取出，所有假设下该片最早可开始取片的时刻均晚于其期限，最小差为 99 刻度，即 12.375 秒。

在项目根目录设置 `PYTHONPATH=src` 后执行 `python scripts/review_archived_recovery.py`，可以离线复核上述两例。脚本默认只检查已有证据。

[一次真实 DeepSeek 调用回执](deepseek-receipt.json)记录所选检查工具、核验状态及供应商报告的用量。模型选择了已有有限边界的核验工具；本地程序独立检查解析上界并重放原方案。该调用与性能对照分别计数。

## 研究记录归档

[记录压缩包](research-records.zip)保留历史比较、输入、逐轮回执、见证与不可行证据的相对路径。[校验清单](archive.json)提供 SHA-256、成员数和批次列表。可将压缩包解压到**空目录**查阅，其中 `results/local/upper-campaign-010/evidence.md` 是最后六例的逐项证据索引。若要按历史脚本读取路径，可解压到新的仓库检出目录。公开包省略账户余额、服务端响应标识、临时构建文件和可再编译的可执行文件；原始本地记录单独保留。
