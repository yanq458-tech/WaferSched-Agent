# 末道冲突与恢复边界实验

[最终验收结果](accepted/README.md)覆盖同一清单中的全部 120 个快照。正式比较只使用 `accepted/` 下成对运行的上一版策略和最终策略。每个输入的两种方法使用相同预算与同一 CPU 核。不同目录的墙钟时间不能相减作为方法收益。

本目录另保留两次诊断迭代，便于追溯决策依据：

- 根目录的 `paired1/` 与 `paired30/` 是第一次试验，使用取片工作量证书、必经故障腔上界和紧凑末道模型。`zero-no-cuts.json` 给出对三个困难输入单独测试立即修复的结果。
- `final/` 是引入零点反馈切换后、加入跨最后取片的驻留总量证书之前的一次完整复测。这次仍有搜索受墙钟限制。保留当时的目录名与原始运行记录。
- `accepted/` 是加入并独立复算驻留总量证书后的冻结版本。此处的实验数值、排序和统计用于最终结论。

中间目录用于追踪诊断过程。原始调用以各自运行文件中的工具轨迹为准。代码指纹在汇总时采集；最终冻结代码的指纹与正式复现实验请使用 `accepted/provenance.json`。
