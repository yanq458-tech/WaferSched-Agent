# 临界维修边界的反馈求解

研究目标沿用故障后全部在制晶圆安全完成剩余路线的最迟维修延迟。新增策略用于已验证的末道子类：空手单臂，源腔和末道腔分离，故障腔为空，各异址移动时间相同，每片剩一道加工及一次出片，加工时间至少为移动时间。专用入口还要求超过 14 片、有限源期限与驻留及进腔持片期限、有可复核的有限路线维修上界。其它输入沿用原策略。所有式子按动作完成端点和后缀整数刻度计算。

## 三种新工具

### 末次源取片之前的腔室容量松弛

记取片、放片、异址移动时长为 P、L、d，令 s=P+L+2d。把每笔搬运从零编号。即使一次进腔后紧接着原地取出同一片，因其加工时间至少为 d，相邻取片开始仍至少相距 s。设 f 是首笔取片开始的下界，最后一笔源取片编号为 K，其开始时刻至多 D（该片取完期限减 P）。在其之前，另外 n−1 片均已进入末道腔；若其中 k 片尚未出腔，则 K=2(n−1)−k。各腔至多留一片，前 K 笔的总额外耗时至多 E=D−f−Ks。

考虑在该前缀完成进出腔的一片。进、出搬运序号为 u、v，令 g=v−u，选腔加工时间为 t，驻留上限为 δ。出腔取片完成距进腔放完有上限，由最短搬运间隔得 gs≤d+L+t+δ。该片在序号区间 [u,v+1) 占去 g+1 笔，且除最短搬运时间外还至少需要 e=max(0,P+d+L+t−gs) 个刻度。理由是从进腔放片开始到出腔取片开始至少需要 L+t。若中间搬运的最短间隔不能填满这段时间，余量须由等待补足。前缀中尚未出腔的一片仅计一笔、零额外耗时，构成下估计。

同腔上述区间互不相交。每个腔的序号数 C≤K、额外耗时之和 A≤E，并有 sC+A≤D−f。若故障腔在前缀中被用到，首个放片开始不得早于 q。截去第一笔取片到放片开始的一段，仍有 sC+A≤D−q+P+d：该笔从放片开始到下一笔取片至少还需 L+d，若是完整进出对还需满足前述加工时间。刻意延迟首笔放片只会压缩该可用时间窗。

小整数模型给每片选择“最后源取片 / 留在某腔 / 在某腔按跨度 g 完成”，保留上述必要条件，最大化 q。每份真实方案都可投影为模型的可行赋值。因此松弛最大值或求解器已证的最大化上界可以收紧真实上界；松弛无解可排除所有维修时刻。松弛的可行赋值不充当调度方案。超时且无有效界则沿用旧上界。[实现](../src/wafer_sched/recovery/feedback/capacity.py)

### 构造可重放的时间表

在若干允许均匀或集中等待的搬运时间网格上，为每片选择“进腔序号、出腔序号、候选腔”。每个序号恰用一次，同腔占用区间互斥。固定较晚维修时刻时，可以把必进故障腔的晶圆放在最后，显式保留持片等待。这个构造搜索只提供下界。失败即回退；若命中已证上界，原 Simulator 先后验证后缀和整机历史，随后关闭边界。适用子类中同一方案还可把维修延迟推到第一次向故障腔放片的开始时刻，经重放后再更新下界。[实现](../src/wafer_sched/recovery/feedback/grid.py)

### 固定维修时刻的精确判定

沿用原完整末道 CP-SAT 模型，固定维修延迟，移除优化目标。新增同腔互斥区间从放片开始延续到出腔取完后 3d+L+P。在同一腔开始下一次放片前，单臂必须把已取出的晶圆送至 OUT 并放下、空移至下一源腔、取片再送回，恰给出这一下界。较晚维修时，若某片只能去故障腔，维修后再服务任何其它源腔都将超过其期限，则这片必然最后离开源腔。若其它已入腔晶圆的最晚取完也早于维修后的首次可服务时刻，则其出片搬运必须在这次源取片前完成。代码按每片期限分别核对这两个前提。

固定 q 的完整模型证无解时，单调性给出新的上界 q−1；q=0 无解才表示即刻维修也无法恢复。求解器对满足性问题返回 OPTIMAL 时仅表示已满足约束。最短完工时间还需要独立下界达到或原优化器证明。[实现](../src/wafer_sched/recovery/feedback/exact.py)

## 决策和预算

四组均为离线计算。旧固定组合是冻结的上一轮原入口；新固定组合和两种反馈入口共用先导求解、容量松弛、网格构造、固定维修精确查询和两层重放。新固定组合先查上界，再按需查零和中间点。反馈策略的先导求解分配原内部预算的 15%。若有见证，先用松弛收紧上界并尝试达到它；若缺少见证，先进行零维修可行性查询，再回到上界。保留已验证下界与当前已证上界，UNKNOWN 不会排除时间点。普通函数和 LangGraph 共用决策函数。原始 JSON 中的 pilot_feedback、defer_upper_relaxation、choose_second_method 和各工具回执可以逐步核对真实路径。
