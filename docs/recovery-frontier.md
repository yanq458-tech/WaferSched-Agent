# 七个未决末道快照的离线恢复边界

本研究从四批已完成实验保存的合法方案和上界继续。仅在原始输入哈希相同、原 30 秒结果未决时读取历史证据。每份继承的方案从故障前历史和后缀重新执行。本轮没有在线模型、外部查询或 API 密钥依赖。

## 上界为何安全

适用条件沿用 `terminal_domain`。每片晶圆还需从独占源腔送入一个合法末道腔，再送往出口。臂初始空闲，候选腔初始为空，异址移动统一用时 d，加工用时至少 d。本模块的增强松弛用于源取片期限和末道驻留上限均已给定的快照。

用 P 表示取片时间，L 表示放片时间，s=P+L+2d。按机械臂实际执行顺序编号，从 0 起。两个相邻搬运的取片开始至少相隔 s。令 A 为最后一次从源腔取片的开始时刻，D 为这片晶圆的源取片完成期限减 P，则 A≤D。K 是这次取片前已执行的搬运数。

1. **首末位置**。每个在此前用过的腔 c，都有第一个占用它的搬运和最后一个占用它的搬运。分别用 h 和 z 表示第一个搬运前、最后一个搬运后的搬运数。不同活跃腔的首位置互异，末位置也互异。
2. **腔内加工跨度**。若某片在 A 前已出末道腔，入腔与出腔两次搬运的序号差为 g，这片在排他腔 c 上占用的序号区间长度为 g+1。同一腔的这些区间互不重叠。加工时间为 t 时，还需至少 e=max(0,P+d+L+t−gs) 个超出基本机械臂节拍的时间刻度。已入腔、尚未出腔者至少占用一项。记计得的序号长度总和为 C，额外时间总和为 E，则 h+C+z≤K，并且 first+s(h+C+z)+E≤D。first 为首笔搬运最早可能的开始时刻。故障腔首次放片必须等到维修结束 q，故障腔另有 q−P−d+s(C+z)+E≤D。
3. **最后一次源取片时的占片**。已占用的末道腔不能成为最后一片此时的目的地，因为机械臂持有最后一片时无法取出原片。不同滞留片在此后的出腔顺序也互异。若某片出腔的相对顺序为 k（从 0 起），它此前最迟在 A−d−zs 放完，此后最早在 A+s+ks+P 取完；这两时刻之差不能超过加工时间加驻留上限。若最后一片进入故障腔，机械臂还要等修复后才能放下该片。
4. **可选的首次故障腔装载分段**。第一次向故障腔装片之前只操作健康腔。固定一个健康腔 H，设其它健康腔在整个前缀内至多提供 M 个搬运。H 在此前已完成的每一对取放之间包含 g−1 个其它腔的搬运，这些内部区间不相交，总数不超过 M。若有 E₀ 个这样的已完成配对，首次故障装载之前的长度最多为 2E₀+1+M。余下搬运受 q 的放片门限约束。相邻配对的额外空闲时间不重复计数；它也不可能落入另一片跨度为 2 的配对之中，因为后者只有一个内部操作。这些约束保留每一份真实可行方案。

每个原模型方案的实际顺序都给出上述松弛的一个赋值。故求解器证明松弛中 q≥Q 不可行时，原问题亦不可能在 Q 或更晚修复。松弛有解只提供必要条件。精确调度边界仍须在同一整数刻度上有完整合法见证。完整查询与松弛查询各自的 UNKNOWN 都不改变已证界。

## 找见证与恢复记忆

有历史见证时，保留并重放最佳调度，固定或扰动机械臂顺序和合法选腔，再用整数差分约束重新安排时间。没有见证时，先在零延迟调用完整精确模型，并用构造搜索尝试给出首份见证。构造中的源期限罚分只参与排序。所有新见证均由原设备仿真逻辑校验取移放、驻留和全片完工，随后再从完整故障历史重放。默认基线与新策略使用相同的归档数据。未决实例的历史最佳上界可以来自不同批次，故表中的比较起点有时比上一批单次成绩更紧。

## 复现

在仓库根目录运行以下 PowerShell 命令。benchmark 必须使用尚不存在的输出目录。每次调用都使用相同的 85% 内部搜索预算，其余留给返回与验证，完整墙钟超时统一计 UNKNOWN。两个方法逐例同核配对，1 秒全量反序复测；30 秒首轮证明类别不同时反序复测。

```powershell
$env:PYTHONPATH=(Resolve-Path src).Path
$env:PYTHONHASHSEED='0'
& ./.venv-langgraph/Scripts/python.exe -m wafer_sched.recovery.feedback.frontier_study benchmark --root results/local/frontier-reproduction
& ./.venv-langgraph/Scripts/python.exe -m wafer_sched.recovery.feedback.frontier_study audit --root results/local/frontier-reproduction
```

正式成绩在 `results/local/offline-frontier-final-004/per-instance.csv`。其中各时限独立，只读取冻结的旧历史。后续累计台账 `ledger.csv` 另纳入本地开发运行和额外诊断的最强证据，不计作 1 秒或 30 秒性能。每个难例的 `certificates/<case>/` 有输入哈希、单独查询状态、压缩的 CP-SAT 模型和已有的完整方案。验证 37.5 秒排除证据只需本机：

```powershell
& ./.venv-langgraph/Scripts/python.exe -m wafer_sched.recovery.feedback.frontier_check verify --out results/local/offline-frontier-final-004/certificates/blind-16-h-f1/historical-upper --seconds 30
```

verify 检查模型哈希，重新交给 CP-SAT，保存本次状态。它属于独立运行复核，未生成求解器无关的形式化证明。时间、硬件负载和搜索速度会影响限时结果。
