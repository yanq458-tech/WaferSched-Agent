# 智能体怎样选择下一次维修查询

给定故障快照，目标仍是确定全部在制晶圆能否完成剩余工序，以及最迟容许的修复时刻。智能体的动作空间只有两个目标：在低端找合法方案，或查询当前上界。前者查立即修复或已验证下界的下一个刻度；后者可能通过无解回执降低上界，也可能通过合法方案直接证明边界。任一目标用尽时只允许查尚未试过的刻度；两端都已查询时回到原有内点规则。

## 学习和反馈

训练集为两个历史队列的 749 条实际查询回执，覆盖 34 个有端点查询记录的设备快照。输入仅包括当时可见的晶圆数、腔室竞争、时间预算、区间、见证和上一轮求解状态。一次查询有三种后果：给出可行方案、排除一个时刻、未取得结论。对于同一快照、同一状态和目标，重复运行合并为一个结果分布。模型不会读取新快照的答案或历史调度方案。

- **原学习策略**用正则化逻辑回归估计返回有效证据的概率。它给找到第一份方案和排除一个刻度相同的训练标签。
- **第一轮改进**进一步估计已取得证据时返回见证的概率，再按当前区间计算预期收益。首次见证、边界闭合各记 1 单位，另加已证区间缩减比例。这一计分标准是人工确定的研究偏好。
- **第二轮改进**在每个历史快照中只选最相近的已观察状态，再汇总多个历史快照的三类回执。按快照留一验证选择邻居数，使用三类结果的 Brier 分数，分数越低越好。没有合法方案时，优先最大化“取得第一份见证，或证明立即修复无解”的估计概率；一旦有了合法方案，就改用上述区间收益。目标优先级由研究者给定，每个动作的结果概率从日志估计。即便还没有见证，模型也可以选择查上界，因为上界处找到的方案同样能交付。

每条决策日志保留当前已证区间、可选动作、候选目标的预测分布、默认查询、实际查询及求解工具回执。只有两个不同刻度都可选时，才能从记录判断模型主动偏好了哪一个。概率是有限历史样本上的估计，只有求解器、冲突证据及仿真回放可以改变数学结论。

## 复核与复现

第一轮改进在独立批次 A 上开发评估，第二轮改进另用独立批次 B。每批 18 例、每例 1 秒及 30 秒，同一组内对比人工策略、原学习策略和当轮新版。每个实例先按均衡顺序运行，然后反序复测。两轮改进的成绩属于不同快照集，不可跨批直接作差。此前丢失见证的旧例另列为开发复查，不计入新快照成绩。

需要项目的 Python 研究环境及四个可绑定的核心 2、4、6、8。耗时包括加载输入和模型、预测、图编排、搜索、方案验证和返回，不包含进程预热与磁盘写出日志。超时计 UNKNOWN，逾时返回的上下界不计成绩。
